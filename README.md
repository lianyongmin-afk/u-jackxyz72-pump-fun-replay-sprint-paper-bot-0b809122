# Pump.fun Replay Sprint — Traction Sniper

A paper-trading bot for make.fun's Pump.fun Replay Sprint: it waits until a new coin proves traction (real SOL reserve ≥ 2 SOL), buys one small fixed stake, takes profit at +25%, cuts the loss at −12%, and never holds longer than 3,000 slots.
